【4. 示教 9 个点】（只做一次。变软时先用手扶住臂；提示"力矩已恢复，可以松手"再放手。
  每个点记录后工具会低速回放一次验证机械臂真能走到，走不到会让你重教。不要用 --presim：真机 J5 方向与仿真不一致会把手腕带歪）
ros2 run mecharm_sort teach_points all
  顺序：格 1→6 取物点（方块放格中心、夹爪张开、压到两指夹住方块中部）→ 左 / 前 / 右各 1 个空中放置点
        （放置点教在空中，离桌面 3-5 cm，到点直接松爪扔下，人随手拿走；前区在网格前方 0.20 m 左右是极限，别再远）
  记录时超出限位（J4 ±155、J5 ±115）会提示重摆——手腕翻转的姿态回放会被拒绝
  放置点手腕姿态要和取物点一样自然（J4 接近 0、J5 在 ±40° 内）；曾出现 J3=45/J4=-56/J5=89 的姿态固件拒绝执行，表现为"到位残差几十度"
  单独补教某一点：
ros2 run mecharm_sort teach_points cell 3
ros2 run mecharm_sort teach_points zone front 0        # front 区放置点
  看教了哪些、还缺哪些：
ros2 run mecharm_sort teach_points show
  低速回放某点核对（先确认周围无人，一人守急停）：
ros2 run mecharm_sort teach_points goto cell 1
ros2 run mecharm_sort teach_points goto zone left 0
  文件：~/Desktop/exp3_taught_points.yaml（放在工作区外面，同步/重编译代码不会覆盖；改完不用重新编译）

【10b. 用 TensorRT 引擎跑 YOLO（可选，更快）】
  在 Jetson 本机转换一次（约 5 分钟，生成 ~/Desktop/yingjiehua/best.engine；换机器要重新转）：
cd ~/Desktop/yingjiehua && python3 -c "from ultralytics import YOLO; YOLO('best.pt').export(format='engine', half=True, imgsz=640, device=0)"
  运行时指定引擎：
ros2 launch mecharm_sort sort_real.launch.py host:=10.42.0.89 model:=/home/nvidia/Desktop/yingjiehua/best.engine
  注：这个模型很小（3M 参数），.pt 在 GPU 上 FP16 已是 ~21 ms/帧，引擎大约再快一倍；画面卡顿主要不是模型，
  是相机帧积压和大图传输，相机节点已改为只发最新帧、调试图缩半。

【11. 可调参数】 ~/Desktop/exp3_sim_ws/src/mecharm_sort/config/real.yaml（改完不用重新编译）
  lift_deg           上方点 = 示教点 J2 往回收多少度（默认 25）
  transit_lift_deg   横移时 J2 再多收多少度（默认 35）
  move_duration / grip_duration   每段动作时长、夹爪时长（默认 4 s / 2 s，越大越慢）
  max_speed          驱动速度百分比上限（默认 20）
  conf               YOLO 置信度阈值（默认 0.5）
  min_markers        至少看见几个码才算定位成功（默认 3）
  state_machine.yaml 里 max_attempts（同格重试次数 2）、max_cycles（循环上限 12，老师加方块多的话调大）
