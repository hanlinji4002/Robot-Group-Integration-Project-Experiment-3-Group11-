# results 验收数据

两次完整运行，均在 Jetson 上无头模式（`gui:=false`）由一个 launch 文件启动，任务开始后无任何人工干预。
每个目录内文件含义见上级 README「四、看结果」。

三组运行都用 **ArUco 网格定位**（`grid_mode:=aruco`，与真机同一套：每次扫描从画面里网格四角的 4 个码算像素→桌面映射，不用相机位姿）。
网格 3×2 连片（格 5×6 cm，行 x=0.105 / 0.155，列 y=+0.06 / 0 / −0.06），桌上没有盒子，分类区是网格左/前/右的空桌面。
